# LogPay

バイトの勤務を記録して, 次の給料日にもらう額とこれまでの支給額を確認する Web アプリです。

https://logpay.oh-gy.com

## できること

- 日付, 働いた時間, 時給を入れて記録する
- 次の給料日にもらう額と, その対象になる期間を出す
- 支給日ごとに履歴をまとめ, 支給済みの累計を出す
- 稼いだ額を月ごと / 週ごとの棒グラフで見る
- 記録をファイルに書き出して, 別の端末で読み込む

## 給料日と締め日

設定の給料日から, 次の支給日とその対象期間が決まります。締め日はあってもなくても使えます。

- 締め日なし: 前回の給料日の翌日から次の給料日まで
- 締め日あり: 支給日の直前の締め日で区切る (当月払いでも翌月払いでもこの規則で決まる)

日は 1 から 31 で指定し, 31 はその月の末日として扱います。2月なら28日 (閏年は29日) です。

## 記録の置き場所

記録はブラウザの中 (localStorage) にだけ保存され, どのサーバーにも送られません。
端末を変えると引き継がれないので, 設定の「記録の持ち出し」から書き出しと読み込みができます。

Service Worker を入れてあるので, 一度開けば通信が無くても使えます。
ホーム画面やデスクトップに追加するとアプリとして開けます。

## 作り

React + TypeScript + Vite。状態は localStorage だけで, サーバーはありません。

| 場所 | 中身 |
| --- | --- |
| `src/lib/period.ts` | 給料日と締め日から対象期間を出す |
| `src/lib/stats.ts` | 稼いだ額を月ごと / 週ごとにまとめる |
| `src/lib/storage.ts` | localStorage の読み書きと旧データの移行 |
| `src/lib/backup.ts` | ファイルへの書き出しと読み込み |
